# Soundpad Web 2.3

Version 2.3 extends the existing project and is published through the normal GitHub Pages website and Windows release. Refresh the website and download the matching 2.3 companion. Older releases remain available for rollback.

## UI and playback

The main tile media surface and slim Play-from-start strip are siblings. Artwork fills its surface, iconless sounds show host-generated cached waveforms, and the gradient covers the media surface. Normal play always starts at the beginning; seeking commits once on pointer release. Tile and player share timeline navigation with cursor-anchored wheel zoom, Shift/middle drag pan, horizontal trackpad pan, touch pinch, Fit and keyboard navigation. Zoom uses existing multiresolution peaks. Advanced cues/regions and millisecond entry are retained under Edit. Space controls playback while leaving editable fields, dialogs and other buttons alone.

Desktop header/player frame independently scrolling sidebar/main panels with hidden tracks. Smaller screens retain the responsive navigation and normal page scrolling. Appearance tokens provide Red & Blue, Original Purple and Ocean. Each browser owns its choice. Notifications stack at the top, deduplicate and expire after approximately four/eight seconds; connection/upload/recovery failures remain inline. AI disclosure remains inline footer metadata and prominent in README.

## Journal and identities

`managed-audio/journal.json` schema 3 tracks sources, uploader ownership, normal/reversed orientation, content hashes, physical file ownership sessions, playback leases, native references, category creation transactions, promotion stages and issues. Public DTOs expose no host paths; authenticated host queries alone include locations. Source changes invalidate generated variants and preserve accepted history. Reverse twice reuses normal audio without another decode/import. PCM16 reversal preserves exact interleaved frames.

Old schema-2 records are copied to `session-audio/journal.v2.backup.json` before migration. Reverse chains resolve to their root with parity and cycle/depth validation. Redundant even-reversal copies retire safely. External native roots are not read until verified against the current Soundpad catalog. Previously accepted flags become protected legacy approvals, shown as needing durable migration; they never silently become disposable files. A malformed journal is preserved byte-for-byte, managed mutations are blocked and ordinary native playback remains available. Repair/restore the journal then Retry recovery.

Personal favorites, categories, hidden/order, cues, regions, zoom, custom icons and web statistics use stable metadata keys/aliases across native promotion. Generated variants stay out of the main grid; their normal/reversed actions live in Temp and the active player.

## Permanent save and recovery

Host confirmation selects a durable local folder and native category, or the app-managed library/Saved category. A plan is persisted before copy/import. Copy uses an exclusive staging file, resumes only matching source bytes, flushes and verifies hashes, then moves into place without overwriting conflicts. Exact native path and intended category membership are verified before commitment. Repeated submissions/restarts find the existing plan and native entry. Temporary sources remain protected until commitment; failed operations expose Retry recovery and retain source data.

Promotion never writes inside managed temporary storage. Category identity includes native index and unique transaction name; the app does not adopt display-name `temp`. An unfinished promotion can block cleanup of its source. Conflicting or externally modified staging/destination files are preserved for host inspection rather than overwritten.

Cleanup is journaled for End hosting, normal shutdown, startup and reconnect. It never stops audio, runs file removal only after STOPPED, and verifies paths/hashes using an exclusive Windows DELETE-capable handle. Permanent and native originals are never deleted. No category is automatically removed. Native index mappings are re-read.

**Production limitation:** the documented Soundpad RC selection-deletion API is not atomic against manual/concurrent selection changes. The production adapter cannot safely supply atomic owned-entry removal, so the app leaves the native entry and file and reports manual recovery. Remove just the listed app-generated entry in Soundpad without deleting its file, then Retry cleanup; once no native reference remains, the app can remove its verified owned file. An explicit atomic path/fingerprint API exists only on isolated test pipes and is never sent to production Soundpad. This is a deliberate safety fallback, not a claim of automatic native deletion in production.

## Bounds and permissions

16 MiB encoded uploads; ten-minute/eight-channel/64 MiB decoded files; 32 temporary files / 256 MiB including staged inputs; 2 admitted processing jobs; 6 new uploads per guest per minute; 2,048 logical sources / 64 variant-history records per source / 4 MiB journal metadata. Decoding has a cooperative 30-second deadline. Source files are local and bounded. Transformation reuse avoids repeated work. Host-authoritative playback/seeking/upload/generation permissions and guest audience ownership are rechecked around asynchronous preparation. A newer Stop/play intent or revoked audience suppresses stale autoplay. Stop/pause do not wait for decoding or durable copying; short native transactions still share the native control gate.

## From the README (moved here in 2.12.3)

Version 2.3 is delivered through the normal GitHub Pages website and Windows release. Refresh the page and download the updated **SoundpadWeb.exe** using the links above. Close the previous companion normally when you are ready to switch; do not overwrite a running EXE. The new Temp features require the 2.3 companion.

- Artwork/waveforms fill the main tile, with a separate slim **Play from start** strip. Waveform seeking commits on release. Five views remain available.
- Zoom toward the cursor with the wheel, Shift-wheel or middle/Shift-drag to pan, horizontal trackpad pan, touch pinch, and **Fit**. The bottom player supports 1–128× zoom; cue/region tools live under **Edit**. Arrow keys select in 10 ms steps (Shift: 1 s), Enter commits, +/- zoom, Alt-arrows pan, 0 fits.
- **Space** pauses/resumes known playback, like YouTube, or stops playback when precise control is unavailable. Text fields, dialogs and other controls retain normal keyboard behavior.
- Desktop sidebar/main panels scroll independently under the fixed header and above the player. Phone/tablet layouts retain normal page scrolling.
- Red & Blue is the default theme; Original Purple and Ocean apply immediately and persist per browser. Small top-corner notifications deduplicate and expire; important errors also remain inline.
- The subdued `made by AI` credit shares the existing footer metadata.
- **Temp** groups logical sources, uploaders, normal/reversed variants, permanent state and recovery issues. Reversing a reversed variant selects the normal source; verified variants are reused. Guests have separate upload and generation permissions.
- **Keep permanently** requires host confirmation, with a local folder and permanent native category. The companion copies and verifies the durable file outside Temp, verifies its Soundpad entry, then retires the temporary version. Personal metadata and web statistics follow stable identities through promotion.
- Uploads and generated variants use app-owned **Temp · Soundpad Web [unique ID]** entries and Soundpad's normal mic playback route. An existing category called `temp` is never claimed.

**Native cleanup limitation:** Soundpad's selection-based API cannot guarantee that another app/user will not change selection between verification and deletion. The production adapter therefore preserves the native orphan and its file, and Temp reports the exact recovery action. Remove only the indicated app-generated entry in Soundpad **without deleting its file**, then Retry cleanup. Cleanup never stops current playback, removes user-owned categories/files, or deletes accepted permanent audio. Automated atomic-removal tests use a fixture-only capability that is disabled in production.

Uploads accept up to 16 MiB, decoded audio up to ten minutes / eight channels / 64 MiB; managed temporary storage is bounded to 32 files / 256 MiB including staged inputs. At most two audio jobs are admitted. Version 2.3 is required for the rebuilt Temp UI. Earlier published changes and acceptance limits are recorded in [V2 history](V2.md); the new lifecycle, migration and recovery details are in [2.3 notes](V2.3.md).
