# Soundpad Studio - offline concept

Open index.html directly in a browser. No installation, server, internet connection, or build is needed.

This separate mockup uses sample content and silent, visual playback. It does not access a microphone or connect to Soundpad, Spotify, or your companion. Reloading resets the demo. The original application files are unchanged.

Try the sound tiles, waveform selection, clickable subtitles, Speaking palette, Record performance, sentence builder, missing-word Gap/Bleep control, and navigation settings.
